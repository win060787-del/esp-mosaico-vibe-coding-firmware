# 桌宠语音输入 3.2.7

点击主界面桌宠进入独立语音页面；额度卡片和底部详情进入任务列表。固定配对一台 Mac，同局域网使用。
桌宠仅显示麦克风、状态和音量动画，不显示转写文字或输入框；文字仅进入 Mac。
点击中央麦克风按钮开始/停止听写，保留音波与状态；短按删除一个组合字符，长按删除本次听写；发送先结束识别再执行一次 Command-Return。
已有 Mac 草稿不被清空。焦点、选区、草稿变化会停止改写，返回后可重新开始。

## 数据与运行

- 麦克风 ES8311：16 kHz、16-bit、单声道，100 ms 采集音频块，每 4 块合并上传，2.4 秒有界 PSRAM 队列；停止时补发尾块。
- 录音期间上传响应同时携带转写状态，不额外轮询；非录音页面约 350 ms 查询一次。
- 固件以 TLS 证书校验和独立令牌连接 Mac。语音通道不经过现有业务服务器。
- Mac 常驻服务使用本地 Qwen3-ASR；每新增约 0.6 秒音频，在上次推理完成后滚动识别。不是原生增量推理；延迟取决于模型和本机负载。
- 单段最长 60 秒、本次文字最多 1800 UTF-8 字节。停止后可以接着录。
- 原始音频只保存在内存和识别期间权限 0600 的临时 WAV，识别后删除，不保留转写文件。
- Mac 输入集成复用了 MI-AO / RemoteVoice 的辅助功能与选区核验实现，见 companion/voice/NOTICE 和 UPSTREAM-LICENSE。
- 录音与提示音互斥。录音期间收到的提示音不播放，任务数据同步照常进行。
- Mac 需要保持开机、服务运行，具备辅助功能权限。发送确认来自输入框清空，不代表 Codex 已完成任务。

## 安装与维护

`tools/install_voice.py` 从本机已安装的遥声/米遥读取模型位置，构建“桌宠语音输入.app”，安装登录自启的 `xyz.novatechai.pet-voice` 服务。
可通过 `--qwen-config` 指定已有的模型配置。当前 Python 环境需安装 companion/voice/requirements.txt。
私有配置、TLS 私钥与令牌仅位于 `~/Library/Application Support/MosaicoCodexPet/voice/`，不打入固件或发行包。
通过官方 Mosaico RPC 0x70/11 将配对地址、证书、令牌写入设备 NVS；重启应用生效。0x70/12 仅返回状态与音频块数量，不返回录音或转写。
当前地址使用安装时的 Mac 局域网 IP；地址改变需重新执行安装与配对。自动发现和多语音目标选择尚未实现。

## 验证范围

自动化覆盖语音会话状态、重复请求、继续听写、组合字符删除、焦点失败和发送不重试；原生模拟器验证真实 C 页面点击。实机采集、识别质量及实际发送须另以设备/输入框证据确认。

3.2.4：模型加载单独显示；业务状态拒绝不再误报为网络断开。手动编辑造成暂停后，重新开始以现有 Mac 草稿建立新会话，不覆盖草稿。

主界面底部优先显示最近完成，完成过期时显示最近交互的任务状态与名称。最近交互由 Mac 采集，经国内服务器下发，不作为新完成事件触发提醒。
