# 3.0.1 多 Mac 与 Wi-Fi 设置

设备通过保留 Recovery 的官方 System Update 流程完成两次无线更新，最终版本为 3.0.1。设备身份为 `4553502d4952495301001c2904d0a33a`。服务端仍是中国大陆广州业务服务器。

设置总览集中提供外观与提醒、终端、Wi-Fi 和无线更新状态。原来的动画、任务详情、声音开关、音量、震动、亮度和六种颜色保留。整个界面使用原生几何与文本，不添加位图资源。

## 终端

- 自动跟随：优先有任务的在线 Mac；当前 Mac 仍在执行时保持选择，避免多台忙碌时跳动。
- 固定终端：一直显示指定 Mac，离线时如实标记，不自动换成另一台。
- 全部汇总：任务按账户和聊天身份去重，额度不相加。不同账户汇总时额度提示按终端查看。
- 添加终端：桌宠生成 10 分钟有效的一次性配对码，重新生成会使旧码失效。Mac 安装程序凭码取得本机专属写入凭证。管理和读取凭证不放入分发安装包。

当前 Mac 已迁移到独立身份并真实上传。新电脑需要安装 `dist/Mac桌宠采集端.zip` 中的采集端并登录 Codex。Apple 芯片运行环境内置，Intel Mac 使用已有 Python 3.9 或更新版本。自动登录启动，电脑休眠或关机后停止上报，超过 90 秒视为离线。

## Wi-Fi

本地记住最多 8 个网络。网络详情可连接、设为首选、删除；删除前确认。断线后按可见网络及优先级尝试，单次 12 秒，全部失败后稍后重试。稳定连接时不会因为顺序改变而主动切断。

从设置添加网络时开启临时 WPA2 热点，名称、随机密码和配网页面地址只显示在设备上。手机连热点后输入网络与密码，密码只保存在设备。热点 10 分钟自动关闭，也可手动关闭。配网写入请求仅接受来自热点接口的连接。

成功连接的凭证同步给保留的 Recovery，后续仍可无线更新。原来的配网已迁移并跨再次更新保留。

- 共享 C 控制器的原生模拟器：设置入口、外观、终端模式、固定终端、配对页、Wi-Fi 详情、删除确认/取消、热点开启/关闭操作通过。
- 完整原生界面回归通过：眨眼节奏、任务转圈、未读绿点清除、完成内容、时钟、返回、声音开关、音量、亮度、六种颜色和电池状态。
- 当前实体设备：终端目录、自动/固定/汇总模式切换、配对码生成、热点开启/关闭通过；增加一个不存在的测试网络并连接，失败后自动回到原网络，同步恢复，随后已删除测试网络。

- 安装包内运行环境已验证 SSL、SQLite 和异步模块可用。

尚未在第二台实体 Mac 或第二个真实路由器验证；多源逻辑通过隔离测试验证，手机实际输入新路由器密码还需在相应环境使用时验证。未将模拟终端注册到生产服务。

凭证只位于用户私有配置和设备 NVS；此文档与安装包不包含凭证。验证数据见 `multi-mac-3.0.1-validation.json`，无线安装回执见 `wireless-3.0.1-update.log`。
