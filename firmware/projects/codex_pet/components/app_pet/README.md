# Codex Pet UI

Portable GSP controller shared by firmware and native simulator. Owns copied state,
blink timer and task drawer. Polls the provided nonblocking source on the UI thread;
no device transport or FreeRTOS dependencies. All GSP mutation stays on that thread.
`app_pet_create` allocates the controller; stop dispatch before `app_pet_destroy`.
`ui/main.json` is generated by `tools/generate_scene.py`; edit the generator.
Fonts retain their licenses. Offline data becomes unavailable after 90 seconds.
Blue completion marker expires ten minutes after the source completion timestamp.
